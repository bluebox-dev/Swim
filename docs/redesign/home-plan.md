# หน้าภาพรวม (Home) — แผนการออกแบบ

## แนวคิด (1 ประโยค)
**ห้องควบคุม:** มี "เวที" สีเข้มผืนเดียวที่แสดงสด ๆ ว่า image เดินทางจากเครื่องต้นแบบ ผ่าน SWIM server ไปถึงเครื่อง Windows ในแต่ละห้อง และด้านล่างเป็น "สมุดบัญชี" สีกระดาษที่เงียบ เรียบ อ่านง่าย มีตัวเลข สิ่งที่ต้องทำ และประวัติ

## อะไรที่ทำให้หน้านี้เป็น SWIM (ไม่ใช่ dashboard ทั่วไป)
- งานหลักคือการทำ image ให้ห้องแล็บ เส้นทางที่สำคัญที่สุดคือ **เครื่องต้นแบบ → image → server → ห้อง → เครื่อง**
- เส้นทางนี้จึงเป็นภาพหลักของหน้า ไม่ใช่กราฟ
- ทุกห้องมีชื่อจริง (เช่น E12-101) และทุกเครื่องมีชื่อจริง ผู้ดูแลจึงมองหาห้องและเครื่องของตัวเองได้ทันที
- สิ่งที่ผู้ดูแลต้องรู้ทันทีมีแค่ 3 ข้อ
  1. ตอนนี้มีอะไรเสีย หรือต้องทำอะไรไหม
  2. มีเครื่องกำลังติดตั้งอยู่ไหม และจะเสร็จเมื่อไหร่
  3. image ที่จะลงคือเวอร์ชันไหน

| Stage | `#08080b` | พื้นของผังระบบ เข้มเสมอทั้งสองธีม เพื่อให้เป็นจุดเด่นจุดเดียวของหน้า |
| Signal orange | `#f28c38` | ใช้เฉพาะในผังระบบ: เส้นทางของ image, กรอบ Control Plane, ไอคอน |

## การเคลื่อนไหว (มีแค่จังหวะเดียว)
- **ตอนเปิดหน้า:** เส้นทางของ image ในผัง "วาด" ตัวเองจากเครื่องต้นแบบไปจนถึงห้อง ภายใน 0.9 วินาที
- **ตอนกำลังติดตั้งหรือสร้าง image:** มีจุดเรืองแสงวิ่งไปตามเส้นที่เกี่ยวข้อง
- **ไม่มี:** การ์ดค่อย ๆ ลอยขึ้นทีละใบ และการ์ดยกตัวตอนชี้
- เคารพการตั้งค่าลดการเคลื่อนไหวของเครื่อง

| หัวหน้าใช้บรรทัดเล็ก "SWIM / ภาพรวม · วันที่" และประโยคคั่นด้วย "·" | เป็นรูปแบบเมตาดาต้าทั่วไป | เขียนเป็นประโยคภาษาไทยธรรมดา 1 ประโยค |

## ตัดออก 1 อย่าง (remove one accessory)
- ตัดจุดสีบอกสถานะ 5 จุดในคำอธิบายใต้ผังออก เพราะสถานะดูได้จากสีขอบการ์ดและป้ายตอนชี้อยู่แล้ว
- เหลือคำอธิบายแค่ 2 อย่าง: เส้นทางของ image และช่องทางควบคุม
