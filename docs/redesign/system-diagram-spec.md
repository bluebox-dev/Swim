# ผังระบบ (System diagram) — รายละเอียดการออกแบบ

การ์ด "ผังระบบ" อยู่ในหน้าแรกของ SWIM ใต้แถวตัวเลขสำคัญ (KPI)
- มีมุมมอง 2 แบบ สลับได้ด้วยปุ่ม **3D | 2D** ระบบจำค่าที่เลือกไว้ในเบราว์เซอร์ (`swim-topo-view`)
- ส่วนอื่นของหน้าแรกเป็นธีม Dashboard ธุรกิจเหมือนเดิม
- การ์ดนี้ตั้งใจให้เป็น "แผงภาพประกอบ" ที่มีชุดสีของตัวเอง
- ข้อมูลในการ์ดเป็นข้อมูลจริงจาก server และอัปเดตทุก 15 วินาที

อ้างอิงที่ใช้:
- **3D** ← ภาพ lesson figure แบบ isometric (16.webp)
- **2D** ← ภาพ data-flow diagram แบบแบน (17.png)

ใช้สีน้ำเงินของ SWIM แทนสีเขียวของภาพตัวอย่าง และไม่ได้คัดลอกโลโก้ ชื่อสินค้า หรือไอคอนของภาพตัวอย่าง

## 3. มุมมอง 3D — รูปทรงและขนาด

**การฉาย (isometric 2:1)**
- หน่วยโลก 1 หน่วย = 30 px
- จุด (x, y, z) บนจอ = ((x − y)·30, (x + y)·15 − z·24.6)

**กล่องทรงหกเหลี่ยมมุมมน ("pillow")**
- **ขนาด:**
  - ด้าน 2.3 หน่วย สูง 2.15 หน่วย
  - หน้าบนบนจอประมาณ 138 × 69 px ความสูงกล่องประมาณ 53 px
- **รูปทรงและผิว:**
  - เส้นรอบนอก (6 มุม) มน รัศมี 16.5 px (เส้นโค้ง quadratic)
  - ทั้ง 3 หน้าถูกตัดตามเส้นรอบนอก มุมจึงมนทุกด้าน
  - **การไล่สี:** หน้าบนอ่อนที่สุด ซ้ายกลาง ขวาเข้มสุด หน้าบนมีชั้นแสงไล่จากขาว 55% ลงไป 0% ที่ความทึบ 70%
  - **เส้นขอบ:** รอบนอก 1.7 px สีหมึก เส้นสันภายในรูปตัว Y หนา 1.1 px ความทึบ 28%
  - **เงา:** ใช้รูปเส้นรอบนอกเลื่อน (+9, +12) px เบลอ 6 px
- **ไอคอนและชื่อ:**
  - ไอคอน (ตู้ server / แผ่น image / จอ) กว้าง 24 px เส้น 1.9 px อยู่เหนือกึ่งกลางหน้าบน 15 px
  - ชื่อ 11.5 px น้ำหนัก 700 วางกึ่งกลาง เส้นฐานต่ำกว่ากึ่งกลางหน้าบน 9 px
  - ชื่อถูกตัดให้พอดีความกว้างหน้าบน (ประมาณ 110 px หรือราว 15 ตัวอักษร) จึง**ไม่ข้ามขอบกล่อง** ชื่อเต็มดูได้จากป้ายตอนชี้
- **การเรียง:**
  - ระยะห่างกล่อง 2.32 หน่วย (ซ้อนกันเล็กน้อยแบบภาพตัวอย่าง)
  - เรียงเป็นแถวเฉียงลงขวาที่ y = −3.4
  - เว้นช่อง 0.9 หน่วยหลังกล่อง Server
- **ลำดับในแถว:** Master (เครื่องต้นแบบ) → Image → Server → เครื่อง/ห้อง

**แท่นทางเดิน (lane)**
- **ขนาด:** เริ่มที่ x = 1.2 ยาวเลยกล่องสุดท้าย 0.4 หน่วย (ยาวอย่างน้อย 6 หน่วย) กว้าง 2.8 หน่วย หนา 0.32 หน่วย
- **รูปทรง:** มุมมน 14 px ขอบ 1.6 px มีเส้นขอบในห่างจากขอบ 0.35 หน่วย และมีเงาแบบเดียวกับกล่อง

**ตัวคน (แทน image packet)**
- **รูปทรง:** หัววงกลม r 6.2 px ตัวแคปซูล 14 × 20 px มุม 7 px ขอบ 1.3 px
- **การวาง:** เดินเป็น 3 แถวบนแท่น
- **จำนวน:** min(30, 14 + 2 × จำนวนเครื่อง)

**ลูกศร**
- เส้นหมึก 1.8 px หัวลูกศรทึบ 7 px จากขอบแท่นขึ้นไปยังหน้าซ้ายของแต่ละกล่อง
- ไปยังเครื่องที่ออฟไลน์เป็นเส้นประ 4/5 ความทึบ 45% และไม่มีหัวลูกศร
- มีลูกศรจาก Image ลงมาที่ต้นแท่น

**ป้ายลอย**
- **ขนาด:** สูง 26 px มุม 13 px ขอบ 1.6 px ตัวอักษร 12.5 px น้ำหนัก 700
- **องค์ประกอบ:** ไอคอนวงกลม r 5 px และแถบความคืบหน้า 34 × 6 px

| ป้าย | ตำแหน่ง | สีแถบ |
|---|---|---|
| ดิสก์ % | ขวาของ Server | เขียว ถ้าใกล้เต็มเป็นแดง |
| ตรวจผ่าน 6/6 | บน Image | — |
| Capture % | บนเครื่องต้นแบบ | — |
| % การติดตั้ง | ขวาของเครื่องที่กำลังติดตั้ง | ฟ้า |
| "≈ HH:MM น." | บนเครื่องที่กำลังติดตั้ง | พื้นส้มอ่อน ไอคอนนาฬิกาทราย |
| ออนไลน์ n/m | ขวาของแต่ละห้อง (เมื่อรวมเป็นห้อง) | — |

**ป้ายคำบรรยายล่าง:** "HH:MM น. · ออนไลน์ n / m เครื่อง" สูง 28 px วางใต้แท่น

**พื้นหลัง**
- ตาราง isometric (เส้นเอียง ±30° ทุก 30 px)
- จางออกที่ขอบด้วย mask วงรี 85% × 80% (เต็มที่ 55% จางหมดที่ 100%)

## 4. มุมมอง 2D — รูปทรงและขนาด

กรอบภาพสูง 490 หน่วย ความกว้างปรับตามจำนวนห้อง (อย่างน้อย 900) พื้นแผงมุมมน 10 px

**เส้นควบคุม (bus)**
- **เส้น:** หนา 3 px ที่ y = 172 จุดต่อวงกลม r 5 px
- **เส้นแนวตั้ง:** ลงไปยังเครื่องต้นแบบ, Image และแต่ละห้อง

**SWIM Server (เหนือ bus ด้านซ้าย)**
- **ไอคอน:** กล่องสีแบรนด์ 76 × 70 px มุม 10 px ไอคอนตู้ server เส้นขาว 2.4 px
- **ฐาน:** แท่งสีเข้ม 96 × 20 px มุม 6 px มีเส้นขาวและไฟสถานะ
- **คำบรรยาย:** "SWIM Server" อยู่ใต้ฐาน สถานะกับเวลาที่เปิดอยู่ด้านขวาของไอคอน

**แถวล่าง (ซ้ายไปขวา)**
1. **เครื่องต้นแบบ:** กล่องสีเข้ม 72 × 66 px มุม 12 px ไอคอนจอสีขาว
2. **Image:** แท่งดิสก์สีเข้ม 3 แท่ง (58 × 18 px มุม 4 px) และโฟลเดอร์สีแบรนด์
3. **ห้อง (สูงสุด 3 ห้อง เรียงจากห้องที่มีเครื่องมากสุด)**
   - **ชิป "PC":** สีเข้ม 44 × 34 px มุม 6 px ห่างกัน 50 px แถวละ 4 แสดงได้สูงสุด 8 เครื่อง เกินกว่านั้นแสดงเป็นชิปเส้นประ "+N" มีจุดสถานะ r 4.2 px ที่มุมขวาบน
   - **แถบห้อง:** สีแบรนด์ สูง 46 px มุม 6 px กว้าง (จำนวนคอลัมน์ × 50 + 14) px ชื่อห้องตัวพิมพ์ใหญ่เว้นช่องไฟ 17 px น้ำหนัก 700
   - **ส่วนล่าง:** กรวยสีเทาลงสู่ฐานสวิตช์สีเข้ม 100 × 22 px
   - **ป้ายวงกลม Agent:** r 18 px วงขาวด้านใน r 12 px หนา 2 px มีเลขจำนวนที่ออนไลน์ ใต้ป้ายมีคำบรรยาย "SWIM Agent / n ออนไลน์"
   - ระยะห่างระหว่างห้อง max(260, ความกว้างแถบ + 120) px

**ลูกศร**
- สีม่วงหนา 2.4 px หัวลูกศรแบบเปิด 9 px
- เส้นทาง: เครื่องต้นแบบ → Image → ห้องที่ 1 → ห้องถัดไป

**คำบรรยาย:** IBM Plex Sans Thai 15 px น้ำหนัก 500 และบรรทัดที่สอง 13 px ทึบ 85% วางกึ่งกลางใต้แต่ละส่วน (y = 446 / 465)

**ห้องที่เกิน 3 ห้อง:** แสดงเป็นป้ายเส้นประ "+N ห้อง"

## 5. สถานะและหน้าตา

| สถานะ | 3D | 2D |
|---|---|---|
| ปกติ / ออนไลน์ | กล่องฟ้า | ชิปเข้ม + จุดเขียว |
| ออฟไลน์ | กล่องซีด ไอคอนและชื่อจาง 60% ลูกศรเป็นเส้นประ | ชิปเข้ม + จุดเทา |
| กำลังติดตั้ง | กล่องฟ้า หน้าบนกะพริบ เรืองแสงฟ้า มีป้าย % และป้ายเวลาเสร็จ มีจุดวิ่งขึ้นไปที่กล่อง | จุดฟ้า ลูกศรเข้าห้องนั้นเป็นเส้นประวิ่ง |
| ต้องดูแล | กล่องส้มอ่อน | จุดส้ม |
| ล้มเหลว (รวมติดตั้งไม่สำเร็จ) | กล่องชมพูแดง + เรืองแสงแดง | จุดแดง |
| Server ผิดปกติ | กล่อง Server ชมพูแดง + เรืองแสง | ข้อความสถานะเป็น "ผิดปกติ" |
| เครื่องต้นแบบ | เปิด = ครีม · ปิด/ไม่มี = ซีด · กำลัง Capture = ครีมกะพริบ + ป้าย % | คำบรรยายบอกสถานะ |
| ห้อง (เมื่อรวมกลุ่ม) | ใช้สีของเครื่องที่สถานะแย่ที่สุดในห้อง + ป้าย "ออนไลน์ n/m" | — |

| ตัวคนเดินบนแท่น | 1 รอบ 16 วินาทีตอนปกติ เร็วขึ้นเป็น 7 วินาทีตอนมีการติดตั้งหรือ Capture เริ่มกระจายตามอัตราส่วนทองคำ จึงไม่จับกลุ่ม |
| กล่องที่กำลังติดตั้ง | หน้าบนกะพริบไปเป็น `#eef4ff` รอบละ 1.6 วินาที ease-in-out ไม่หยุด |
| จุดวิ่งไปเครื่องที่กำลังติดตั้ง | รอบละ 1.1 วินาที |
| ลูกศร 2D ตอนกำลังติดตั้ง | เส้นประ 10/6 วิ่ง รอบละ 1 วินาที (linear) |
| ป้ายข้อมูลตอนชี้ | แสดงทันทีตามตำแหน่งเมาส์ |
| ปุ่ม Pause / Play | หยุดหรือเล่นแอนิเมชันทั้งหมดในภาพ |

## 7. การรองรับจำนวนเครื่อง

- **3D**
  - ไม่เกิน 10 เครื่อง: แสดงกล่องละเครื่อง (สูงสุด 9 กล่อง เกินจากนั้นแสดงป้าย "+N เครื่อง")
  - เกิน 10 เครื่อง: รวมเป็นกล่องละห้อง เรียงจากห้องที่มีเครื่องมากสุด แต่ละห้องมีป้าย "ออนไลน์ n/m" แสดงสูงสุด 9 ห้อง เกินจากนั้นแสดงป้าย "+N ห้อง"
  - ภาพปรับขนาดให้พอดีกรอบเสมอ
- **2D:** สูงสุด 3 ห้อง ห้องละ 8 ชิป เกินจากนั้นเป็น "+N" ทั้งระดับเครื่องและระดับห้อง
- **มือถือ**
  - 3D ย่อลงพอดีจอ
  - 2D เลื่อนซ้ายขวาได้ (กว้างอย่างน้อย 760 px)
  - กล่องตัวเลขแสดง 2 คอลัมน์ หัวเรื่อง 22 px

## 8. สิ่งที่ทดสอบแล้ว

- **ข้อมูลจริง (1 เครื่อง):** 3D และ 2D บนจอ 1440 px ทั้งโหมดสว่างและมืด
- **ข้อมูลจำลอง** (ในเบราว์เซอร์ของผมเท่านั้น ไม่ได้ส่งอะไรไปที่ server)
  - **10 เครื่อง 3 ห้อง:** 1 เครื่องกำลังติดตั้ง 62% พร้อมป้ายเวลาเสร็จ, 1 เครื่องต้องดูแล, 3 เครื่องออฟไลน์
  - **40 เครื่อง 5 ห้อง:** 3D รวมเป็นกล่องละห้อง และ 2D แสดง 3 ห้องกับป้าย "+2 ห้อง"
- **มือถือ 375 px:** ทั้ง 3D และ 2D
- **การใช้งาน:** ชี้แล้วเห็นป้ายข้อมูลและคลิกเพื่อเปิดได้ทุกส่วน, สวิตช์ 3D/2D และการจำค่า, ปุ่ม Pause และ Replay
- **ยังไม่ได้เห็นจริง:** ภาพตอนมีเครื่องกำลังติดตั้งจริง (ทดสอบด้วยข้อมูลจำลองเท่านั้น)
